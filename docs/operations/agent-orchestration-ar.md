# تنظيم العمل بين القائد والوكلاء

## النموذج المعتمد

يعتمد المشروع نموذج:

**قائد تطوير مركزي + وكلاء متخصصون لكل موديول**

القائد المركزي مسؤول عن:

- تثبيت المعمارية.
- إنشاء Foundation.
- تحديد conventions.
- توزيع المهام.
- مراجعة مخرجات الوكلاء.
- دمج العمل النهائي.
- منع التداخل.

الوكلاء مسؤولون عن:

- تنفيذ موديول محدد.
- الالتزام بالوثائق.
- عدم تعديل نطاقات غير مملوكة لهم.
- تسليم مخرجات قابلة للمراجعة.

## قاعدة مهمة

لا يعمل وكيلان على نفس الملفات أو نفس الجداول إلا إذا تم تقسيم الملكية بوضوح مسبقا.

## ملفات الملكية الأولية

- Foundation: `app/`, `config/`, `database/migrations/*foundation*`, `app/Filament/*`.
- Social Care: ملفات المستفيدين ودراسات الحالة والطلبات.
- Donations/Store: المشاريع والحملات والداعمين والدفع والموقع العام.
- Finance/Inventory: الحسابات والسندات والمخزون والتوزيع.
- Governance/Archive: المجلس والحوكمة والوثائق والاتصالات.
- QA/DevOps: الاختبارات والنشر والتقارير العامة.
